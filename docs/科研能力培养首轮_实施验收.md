## 检查策略与兼容

核心教学默认经过助手、小白、校验。补基础、研究思路、方法图表、机制、专业细节及能力迁移不能因选区、附件、程度调整或旧 readabilityCheck=false 而省略试读。仅对当前已交付文字明确请求通俗改写／压缩时保留轻量来源核验；已有直接背景路径收窄到简短定义和其续接。更改来源事实的低风险自动升级还需后续更完整的内容影响合同。

讲解程度调整默认作用于本轮；设置中的选择按聊天保存，“以后都……”明确请求才保存偏好。新合同优先于旧 depth，旧会话读取时由原值兜底映射，不重建或删除私人数据。并发设置更新受到 preferenceRevision 保护，不被运行中旧状态覆盖。程序为旧任务入口补全共同意图。

小白取得公开意图、画像、可见解释／图注和已教概念；未增加原文块、校验报告或隐藏答案。当前小白仍返回试读反馈；具体复述规则的加入不等于独立开放行为已完成。

阅读起点最多读取 10 个非空正文来源、每项最多 1800 字符；记录提供片段、截断片段和可用总数。前端展示覆盖范围。旧模型、旧规则及旧键下的记录保留为历史，不返回为当前有效概述。

使用 Node 24.19.0、Microsoft Edge；本轮没有生产模型调用。自动测试使用固定响应和模拟 HTTP 传输，不将其报告为真实学习效果或国内能力验收。

- `checks/browser-learning-intent.ts`：旧值 API 迁移、两组独立选择、背景保留、问题草稿保留及刷新恢复通过；1280／1440／1920 桌面窗口及 100%／125%／150% 等效 CSS 视口、浅深色下控件可访问。等效视口检查不能替代原生浏览器缩放或真人体验。
- `checks/browser-materials-tools.ts`：附件、精确 PDF 选区、原生 PPT、设置／记录、手动补原文和布局回归通过。
