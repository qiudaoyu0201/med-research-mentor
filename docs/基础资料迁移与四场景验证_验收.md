本轮实现基础资料目录、通用选材、一次补讲、来源快照及缓存／导出校验。工程验证通过；真实开发验收有三个场景通过，三页汇报尚未通过，详见第 6 节。主对话前端维持原范围。

本轮迁移的是“当前论文证据＋可复用基础”的组织与讲解流程。没有把 Xu 的实验条件移植到 Hewitt，也没有增加模型训练或任意主题自动检索。前端仍是原来的四入口。

## 1. 迁移如何落地

论文提供图、图注、结果和方法；基础目录提供可复用的概念解释。每次任务按当前问题和当前材料匹配目录，不要求论文属于预设 ID。

- `materials/foundations.ts` 保存原有五个独立 PCR／qPCR／流式来源，示例包引用它们。
- `server/foundations.ts` 登记条目、别名、依赖、版本、范围、事实出处与已读范围。错误引用、缺依赖与循环依赖会被拒绝。
- `server/materials.ts` 按完整图号与 `relatedFigures` 选证据，Figure 1 不匹配 Figure 10。Xu 提取适配仅保留作样例，运行选择器没有 Xu 来源 ID 特判。
- `server/paper-assets.ts` 为上传 PDF 显式登记图、结果与方法；段落按原页和起止锚点定位，图像来自实际 PDF 原页。不推断某方法适用于某面板。
- 独立方法会话使用 `foundation-only`，不加载默认论文。换论文清除旧教学摘要、未解决项及证据绑定，重新取得当前材料；通用目录仍可复用。

新增主题按相同格式登记内容、出处、别名和依赖即可接入，不需要修改路由。服务消费本地已核验目录，未实现任意主题自动联网检索或前端目录管理。

## 3. 断点与审计

箱线图基础新增 [NIST Box Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/boxplot.htm)与[Measures of Location](https://www.itl.nist.gov/div898/handbook/eda/section3/eda351.htm)的定义，核对排序、中位数、四分位数和不同须定义。TAF 1.0.1 明确补充两类信号在同一空间位置重合的解释；出处仍为已读 Hewitt 方法与原图，未增添当前论文未提供的共定位算法。

讲解前本地匹配不新增模型调用。教学、模拟新手和核对后再查具体断点；可补基础进入剩余的一次修订。已有资料但解释不足也可以补讲；未知资料保持待处理，不启动额外循环。

`materialRequests` 保存原问题 ID、概念、用途、论文版本、匹配条目与 pending／provided／resolved。provided 不代表解释通过，复读及核对明确解决后才改为 resolved。论文方法缺失不能被通用基础替代。额度容纳不下必要基础也会保存明确请求。

`materials` 保存初始及补入后的来源快照与哈希。角色输入使用独立副本；更新修订资料不会回写首轮审计输入。新手只看可见讲解、图注及完整汇报，不取得方法原文、核对报告或评价条件。

去重正文最多 20,000 字符；图注与元数据额外输入按实际调用记账。关键图注和已登记结果／方法不能被静默丢弃。目录与选材规则版本参与缓存；未解决或中途补资料的结果不发布到旧缓存键。导出校验最终来源快照，基础内容或论文版本改变后需重新核对。

当前目标仅理解读数时，范围外的完整复现流程明确列为限制；用户实际请求复现／计算时，其缺失必须保留为未解决问题。必要基础仍要求出处与解释，内容评价仍拒绝只列缩写或关键词。

## 4. 登记接口与操作

上传后调用 `POST /api/papers/:id/evidence`：

```json
{
  "number": "1",
  "page": 3,
  "results": [{ "page": 2, "start": "结果起始原句", "end": "下一段起始原句" }],
  "methods": [{ "page": 8, "start": "方法起始原句", "end": "下一方法起始原句" }]
}
```

页码为 PDF 实际页序。自动图注定位当前支持明确的 `Figure N |`／`Fig. N |` 标签；其他排版需使用现有圈选及人工完整图注。自动提取资料仍标为未逐段人工校对。补充原文接口 `/api/papers/:id/text` 可附 `section`（results／methods／overview）和 `relatedFigures`，关联由登记者确认。

接口实测用新上传随机 ID，真实图／方法登记成功，Figure 10 被拒绝，补充段落关联字段得到保存。记录 `runs/transfer-api-check.json`，零模型调用；原页图 `runs/hewitt-fig1-page.png`。
