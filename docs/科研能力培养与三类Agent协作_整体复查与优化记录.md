## 3. 已定位的当前问题

优先级 P1 表示影响核心结果或恢复，应在进入内部迭代前处理；P2 表示影响效率、表达或结论可信度，按相同任务的效果比较修复。下列均未因本轮文档修订而关闭。

### A01 · P1 · 普通 PDF 没有可用于 PPT 的图件来源

`server/pdf.ts` 普通导入登记逐页文字、页码和 PDF 地址，没有建立图件图像、图号及区域。对同一份真实 Xu 2018 PDF 按普通路径解析，本轮得到 15 页、15 个逐页来源、**0 个图像来源、0 个图件来源**。

`server/sample.ts` 与 `server/paper-assets.ts` 对示例或显式登记材料另行绑定图像；它们不能证明普通上传路径已具备同样能力。需要从普通论文入口到实际 PPTX 验证完整配图，不只验证固定示例。

### A02 · P1 · 默认 PPT 生成把已有论文图片排除了

`app/research-ppt.tsx` 生成请求包含附件及 `kind === paper && !image` 的来源；`server/materials.ts` 默认 PPT 来源也排除原图。实际捕获示例论文的提交参数：可用图像为 `xu-fig1`、`xu-fig6`，提交的图像来源却为 **0**。

因此这既有提取缺口，也有来源装载缺口。单独裁好一张图不会自动解决整条链路。

### A03 · P1 · 手动裁剪没有进入 PPT，现有补图提示也不够闭环

阅读器只按论文／版本／页／来源在浏览器保存选区坐标。`Slide` 没有图件区域字段，显示资产保存整页或附件，导出未读取阅读选区。单页修改还要求保留原图绑定，编辑器只有标题、要点和讲稿。

PPT 中“添加清晰单图后另存版本”的提示没有配套的指定页替换图件入口；不能把上传补图和生成新版笼统称为已完成原页局部替换。配图修复要覆盖来源、区域、保存版本、预览和导出，保持操作简单。

### A04 · P1 · 网页预览与导出布局不同，整页图在成品中难以使用

网页用纵向内容卡片，原页图显示约 **838 × 1113 CSS 像素**，需要滚动。`server/export.ts` 用固定横版布局，把图片限制在 **5.05 × 3.7 英寸**的右侧区域。

本轮用 PowerPoint 实际打开并渲染导出的八页示例：第 5 页把论文整页压到右侧小区域，图表标签和原文细节难读。网页可以打开大图，不能据此认定汇报文件已经清晰。

### A05 · P2 · 最终内容仍有过密出处和过多核对说明

实际渲染已有真实三页 PPT：第 2、3 页脚注集中放长来源标题和定位，视觉密集；第 3 页主体大半用于材料／核对限制，科学局限和产品材料状态混在一起。该样本原请求明确只用片段、不强求图片，因此不据此判定事实捏造或所有 PPT 都如此。

`server/export.ts` 把全部来源标题／locator 拼成脚注；研究方案 Markdown 还输出 `proposal`、`assistant` 等内部标签、较长来源摘录及重复限制。出处和范围要保留，但应简短、与用途匹配，避免内部元数据挤占成品正文。

### A06 · P2 · 长论文材料选择和生成速度未达目标

普通解析得到 99,305 字符，当前 20,000 字符选择本轮留下第 **1、2、4、11** 页、19,568 字符；含相关方法的第 **12、13** 页没有进入这一默认请求。它证明存在覆盖缺口，不表示这些页对每个问题都必须提供。

已有三页 PPT＋完整稿任务用了六次调用，累计 Provider 调用时长 **217,209 ms**，账本 token 合计 **144,304**；补写演讲稿两次累计 **60,994 ms**；观察研究框架两次累计 **48,042 ms**。这是一组历史实测，不是所有任务的平均值，也不是金额估算。

当前 PPT 默认进入教学、试读、核对，必要时修订／复读／复核，与主方案希望在线轻量、按需诊断的方向仍有差距。优化需要固定材料和目标比较输出，保留必要事实核对，避免机械加角色或仅减少调用数。

### A07 · P1 · 损坏恢复只覆盖 JSON 语法错误

`RecordStorage` 隔离 JSON 解析失败；可解析内容没有按记录类型校验。本轮独立夹具保存 `{id, status: queued}` 的阅读起点记录，读取成功，但启动所用 `ReadingGuides.restore` 报 `Cannot read properties of undefined (reading 'attempts')`。

工作区索引 `{}` 也能恢复进入内存，创建课题时报缺少 `projects.push`。夹具只在独立目录运行，没有破坏用户记录。现有语法损坏隔离是真实完成项，结构损坏处理仍未完成。
