## 使用限制与后续验收

- 原文核对的范围由本次提供的资料决定：本机示例接入原文页段；正文文件缺失时回退局部摘要。出处存在不代表已经独立审查全文。
- 图片与图注需要人工确认。支持 PDF 圈选、补图注和保存图件；示例提供 Figure 1、6 所在原页，缺图时只占位。箱线图、生存曲线、火山图、流式真实图等尚未全部建立并验证独立图库。
- 基础课程来源仍较小，不能覆盖所有参数、算法和实验操作。真实新手与老师反馈尚未加入，临床论文适配尚未验证。
- 没有扫描 OCR；复杂排版的提取文字可能乱序。手动补充材料标为待核对。
- 模型接口按当前本机 CLI 类型适配，不保证以后版本完全兼容。不复制登录文件、不切付费 API、不购买额度。格式与网络失败停止并保留记录，重启标中断。
- 运行按来源与 skill 内容哈希记录版本；当前不启用答案缓存，避免旧规则答案误用。缓存键函数为后续缓存准备。
- 大纲编辑可以改变内容，因此导出检查来源和结构，不能自动证明用户修改后的每一句仍正确。未知来源 ID 拒绝导出。
- 服务为单人本机程序，数据未加密，不提供账号、多设备同步、多人共享或公网部署。

首次短文本生成及示例 qPCR 的初次结构失败也有记录。结构失败源于服务对 JSON Schema required 字段的要求，已修正；失败任务没有自动重发，后续新任务由本次开发验证主动发起。
