# 医学文献汇报 PPT 的参考吸收约定

2026-10-25 用户再次要求保留这次阅读评价，作为持续迭代依据。参考为用户提供的 15 页《AI皮肤癌分诊文献汇报 npj Digital Medicine 2026》；逐页审阅材料保存在被 Git 忽略的 runs/reference-reviews/skin-cancer-20261025-33eaa07e。以下是内容与表达上的启发，不是固定页数、版式配额或新的审批门槛。

## 应持续吸收的六点

1. **给研究主线必要的空间。**按“为什么做—怎样做—结果怎样—有什么意义”组织。参考第 2—5 页分别承担背景、缺口、内容与整体设计。目的、思路或创新需要独立推理时可以分开；根据研究复杂度和汇报时长分配页面，不为简洁硬压在一页，也不强制每个栏目各占一页。
2. **把适合图示的关系画出来。**参考第 3 页的左右对照、第 5 页的数据与验证路线。先判断内容的真实关系，再选择流程、对照或其他支持的图解；分支不伪装成先后顺序，不靠装饰性方框制造图表。
3. **方法保留读懂结果所需的中间步骤。**参考第 8 页交代参与者、独立判断和 AI 辅助判断的比较、参照标准与顺序。专业听众需要知道“谁对什么做了什么、比较什么、怎样形成读数”；必要理由不能跳过，次要操作细节才放简短讲述提示或确有需要的备用页。避免变成新手教材。
4. **按内容变化页面表达。**参考分级卡片、原图配关键量、流程和阶段对照。统一视觉语言，同时让问题、设计、比较和证据页有不同任务。不能用所有页面同一组项目符号替代汇报，也不要求每页使用不同模板。
5. **每幅图服务当页问题。**应能说清图片或面板支持哪一个判断。讲什么展示什么，裁切保留轴、单位、组别和图例；只有解释全图结构时才用全图。不同结论不能反复原样铺同一图。没有对应证据图时，用忠于来源的文字或图解，不补造论文图。
6. **结尾收回研究贡献。**可按模型表现、辅助人的判断、实际流程等研究真正涉及的层次提炼发现，并接回前文证据。选适合该论文的层次，不套固定三层结论；减少与前页重复的限定语和总结页。

## 参考稿中不能照搬的地方

- 第 9 页中文图序说明与原图图注顺序不一致。使用前需核对图与图例，而非照抄中文说明。
- 第 11 页列出的 280 降至 214，对应相对下降约 23.6%，不能据此写成 30%；第 14 页复用的同一数字也需核对。
- 第 8、11 页存在截图裁切不完整、夹带无关正文或文字偏小的问题；学习选图目的，同时改善裁切与清晰度。
- 第 13—15 页仍有总结与边界表述重复。必要限制在影响判断处讲清，不逐页重复成防御性写作。

这些问题来自所提供 PPT 的逐页阅读，不代表已经核实全部原始论文或所有结论。

## 与既有成果合并

保留证据可追溯、数字与区间、图文对应、专业但不跳步、必要边界就地说明等已积累要求。nature 类技能用于对照证据和论证，ppt-master 类项目用于对照叙事、密度与视觉表达；参考项目的规则不自动成为本产品的硬限制。实际模型输出必须导出并逐页检查，机器评分或无文字越界均不能代替视觉评价。
