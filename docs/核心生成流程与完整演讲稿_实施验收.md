日期：2026-10-06 · 基线：1ee0062（main）

按用户最新要求，优先让讲解、PPT、研究方案生成容易找到、快速使用。必要流程和辅助功能保留，保持原有排版、区域比例与视觉平衡。本轮落实研究方案一键生成、可选完整演讲稿，并纠正通用选项对单篇实验论文的偏向。

## 已完成

- 研究方案：输入课题后直接“生成方案”，程序自动创建记录并提交生成任务。保留条件补充、来源选择、生成进度、核对、本轮建议、分节编辑保存、版本恢复、停止及 Markdown 导出。提交失败可沿用原请求重试，避免多建方案。
- 新 PPT：汇报要求可空着直接生成，勾选“同时生成完整演讲稿”才生成完整稿。页数、材料、笔记、逐页讲稿、预览、页面编辑与 PPTX 导出保留。
- 已有 PPT：在原预览区的“完整演讲稿”折叠项中补写、重新生成、编辑保存和独立下载 Markdown。完整稿含开场、按页讲述、转场和结尾；复用已有 DeckVersion、模型队列、账本和来源核对，不另建管理专区。
- 手改稿：本机暂存并可刷新恢复；未保存时禁止直接重新生成覆盖。保存只核对，不让模型重写用户文字。失败、取消和后台重启保留原 PPT、旧稿及候选内容。改页后的新版本不套用旧完整稿，旧版本可恢复。
- 通用性：汇报默认要求、讨论入口和学习背景不再预设特定实验技能；PPT 材料选择包括方法段落。示例论文保留为示例，生成结构随实际研究类型调整。

三个核心入口、辅助功能位置和整体布局保持原样；本轮未添加研究方案转 PPT、独立演讲稿管理、复杂必填表单或新导航。

## 范围与保留问题

真实 PPT 的首次联合核对发现术语表达不清，修订并复核后完成。观察研究方案生成与导出成功，但核对仍保留一项警告：无法连接患者身份的重复随访记录不能直接视作独立样本；界面未将该草稿宣称为完全通过。

这些证据验证工程流程及有限案例，不等于广泛医学科学有效性、真人试讲效果或全部研究类型均已成熟。内部 paper-lookup、自动磨合、独立迁移与国内模型真实验收仍按整体方案后续实施，不占用本轮三个核心功能的主体。

## 原文阅读精简与精准局部查看（2026-10-06）

- 每条讲解保留一个“查看 PDF 原文”入口，同页来源跨段合并；涉及多页时在入口旁按需选择页码，补充来源折叠保留。PDF 下方不再重复铺排解析正文和长图注；没有 PDF 的摘录、上传图片和补充来源仍可展开阅读与选中文字提问。
- 原有 PDF 阅读器增加“框选局部”：由用户拖动选择图或段落，按页面坐标重新渲染该区域，保持原文的字体、公式和图形。选区可覆盖单个面板、多面板、图和图注或整页，不限制为小范围；局部预览等比缩放显示完整选区，支持查看大图和返回整页。取消框选不会覆盖已有范围。仅在浏览器保存坐标，按论文、来源版本、页码及来源分别记忆，不修改原 PDF。当前为手动精确选框，不宣称自动识别每张图或自动匹配讲解。
- 复用已有 PDF.js，依据 [Mozilla 官方示例](https://github.com/mozilla/pdf.js/blob/master/docs/contents/examples/index.md) 的 viewport 与 canvas transform 机制实现；没有引入额外裁剪依赖。裁剪校验、像素边界处理及画布大小限制避免坏缓存、缩放偏移与过大的局部画布。

## 日常错误修复与导出规则收尾（2026-10-07）

- 按用户最新要求，研究方案与 PPT 统一为成功完成核对后导出。方案未核对、核对调用失败、有阻断问题或对应任务未完成，界面禁用导出，后端直链返回 409。手改和恢复稿不沿用旧核对；再次核对后才能导出。新任务失败不影响先前成功历史稿。失败草稿保留供修改，不再提供带问题导出选项；取消、条件补充、编辑、保存和正常核对保留。
- 方案界面收掉“按原额度恢复核对”、逐次角色调用账本及长能力范围说明。失败时直接显示失败及原因，导出旁给简短提示；正常生成和修改仍使用原有入口、分栏和默认阅读布局。
- 工作区轮询携带资料指纹，服务端只传变动的论文，避免重复发送原页图像；初始导航仍返回完整快照，附件内容、来源版本和新论文都会纳入指纹。讲解、PPT 与方案空闲时约每三秒同步，运行任务约每 900 ms 同步，后台页面降频，回到前台立即更新；上一轮完成后才安排下一轮，新任务可唤醒同步。PPT 原定时器重叠请求也已移除。
