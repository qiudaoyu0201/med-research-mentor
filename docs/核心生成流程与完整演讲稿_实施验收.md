# 核心生成流程与完整演讲稿实施验收

日期：2026-10-06 · 基线：1ee0062（main）

按用户最新要求，优先让讲解、PPT、研究方案生成容易找到、快速使用。必要流程和辅助功能保留，保持原有排版、区域比例与视觉平衡。本轮落实研究方案一键生成、可选完整演讲稿，并纠正通用选项对单篇实验论文的偏向。

## 已完成

- 研究方案：输入课题后直接“生成方案”，程序自动创建记录并提交生成任务。保留条件补充、来源选择、生成进度、核对、本轮建议、分节编辑保存、版本恢复、停止及 Markdown 导出。提交失败可沿用原请求重试，避免多建方案。
- 新 PPT：汇报要求可空着直接生成，勾选“同时生成完整演讲稿”才生成完整稿。页数、材料、笔记、逐页讲稿、预览、页面编辑与 PPTX 导出保留。
- 已有 PPT：在原预览区的“完整演讲稿”折叠项中补写、重新生成、编辑保存和独立下载 Markdown。完整稿含开场、按页讲述、转场和结尾；复用已有 DeckVersion、模型队列、账本和来源核对，不另建管理专区。
- 手改稿：本机暂存并可刷新恢复；未保存时禁止直接重新生成覆盖。保存只核对，不让模型重写用户文字。失败、取消和后台重启保留原 PPT、旧稿及候选内容。改页后的新版本不套用旧完整稿，旧版本可恢复。
- 通用性：汇报默认要求、讨论入口和学习背景不再预设特定实验技能；PPT 材料选择包括方法段落。示例论文保留为示例，生成结构随实际研究类型调整。

三个核心入口、辅助功能位置和整体布局保持原样；本轮未添加研究方案转 PPT、独立演讲稿管理、复杂必填表单或新导航。

## 范围与保留问题

真实 PPT 的首次联合核对发现术语表达不清，修订并复核后完成。观察研究方案生成与导出成功，但核对仍保留一项警告：无法连接患者身份的重复随访记录不能直接视作独立样本；界面未将该草稿宣称为完全通过。

这些证据验证工程流程及有限案例，不等于广泛医学科学有效性、真人试讲效果或全部研究类型均已成熟。内部 paper-lookup、自动磨合、独立迁移与国内模型真实验收仍按整体方案后续实施，不占用本轮三个核心功能的主体。

## 取消与导出补齐（2026-10-06）

按“常见操作要用心做、必要时才提供撤回”的要求，仅补齐当前任务和未保存修改的退出路径，未扩展通用撤回系统。

- 讲解、PPT 生成、单页修改、完整演讲稿和研究方案任务：在原进度区域取消，排队时撤回、执行中停止；取消期间显示“正在取消…”，重复点击不重复发送。后台确认结束后更新状态，保留旧产物、候选与未保存手稿。
- 研究方案的未保存条件和正文、完整演讲稿的未保存改稿：仅在确实有修改时出现放弃入口；恢复已保存内容、同步本机草稿，不要求先保存不想保留的修改。单页 PPT 原有放弃编辑入口保留。
- 并发范围：保留同论文任务排队与真实来源／版本冲突检查；移除其他论文的改页任务对恢复保存版本的全局阻塞。导出已完成 PPT 不再被讲解或生成队列阻塞，导出记录通过原子会话更新合并，也不改变当前选定版本。
- 演讲稿：正文旁提供 Markdown 和 TXT 导出，均导出确切保存版本。未保存稿先保存或放弃，旧稿与 PPT 备注导出照常保留。

本次构建与 128 项测试通过；新增排队演讲稿取消零调用、取消后再提交、跨论文恢复验证。浏览器夹具（零模型调用）验证 PPT／稿件取消后按钮恢复、旧稿保留、放弃改稿、两个稿件导出入口、方案取消与草稿退出，并通过多聊天排队取消回归。原真实模型案例仍作为有限产物证据，本轮未额外调用模型。

## 来源返回、字体、底框与手写笔记（2026-10-06）

- PPT 的来源按钮在当前汇报内打开原有资料阅读器，用“返回 PPT 汇报”或 Esc 关闭。保持当前保存版本、页码、编辑草稿、展开状态和预览节点；对原文发起解释时才进入论文讨论。复用原有 PDF 定位、来源阅读和笔记能力。
- 导航、正文、表单和控件默认统一为系统无衬线字体，使用常规字重与适当行距；旧默认偏好迁移一次，之后用户主动选择仍会保存。原始 PDF 字体不改写。来源正文调整为 16px，标题不超过 600 字重。
