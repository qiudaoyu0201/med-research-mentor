## 1. 整体判断与不变目标

产品面向医学科研小白，通过主体教学、并列的研究方案／PPT 专区帮助其理解问题、方法和证据，并逐步形成迁移能力。实际成品能用与学习能力形成均需关注，不能相互替代；能力来自底座大模型、经适配的成熟 Skill、多论文案例和有证据的迭代。

## 4. Agent 配合的完整路径

**内部材料准备：** 开发侧提出明确医学能力缺口，程序有界检索、核对身份／用途、归并与冻结分池；助手只用开发材料提炼原理与条件，校验核对来源及冲突。公开目标材料按协议提供，隐藏答案隔离。结果首先是已核来源／案例，不是能力提升。

**内部闭环 A：** 助手生成新课题方案、PPT 与所选稿件，校验直接核对科学依据、设计取舍、表达和真实文件；PPT 代表案例由学过的小白试讲和初始听众诊断。校验判断断点来自产物、教学、材料还是模拟，把具体问题交助手修改／提候选；程序在固定比较、回归和留出支持后发布对应制作能力。

**内部闭环 B：** 助手以实际多论文单元教学，小白从真实可见历史进入隔离的新目标任务，自行设计／组织并说明理由；校验核对原稿、适配与辅助，反馈助手补教。修订同题记录纠错，另一个未见目标检验再迁移。未学习／只给材料／教学分支按固定条件比较，不能靠降低小白基线或泄漏答案制造收益。

**用户使用与改进：** 主体和双专区调用适用清单，助手帮助、校验轻量核对；小白用于所选解释／试讲诊断，真实用户可自愿先试。用户语言先适配当前需求；明确范围的偏好和获准共享反馈分别处理。当前改稿先满足用户，通用改进进入后续有界批次；不在每次用户交流后自动训练。

程序保障过程，三角色给出内容证据。校验和小白同样需要校准，源文／已核事实／必要专业审阅是外部依据；三个模型互相同意不足以构成科学真值。

## 6. 落地取舍与未关闭事项
