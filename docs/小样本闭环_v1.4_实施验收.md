# 小样本闭环 v1.4 实施与验收

2026-10-08，实施起点 `2624aa9`，在 main 完成。以[执行方案 v1.4](小样本闭环与整体交付_落地方案_v1.4.md)为依据，采用产品诊断路线，保留线上教学基线；不新增第四候选，不把本轮材料计为独立留出。

## 工程落地

- `training:short` 复用第三周期原 report、TrainingProvider、TaskManager、ResearchPlans、DeckVersions 及正常导出。三个开发样本冻结实际片段、来源版本、问题、输出范围和评价条件；生成输入不包含评价答案。Passos／Bell、握力／血脂保留，未用于调优。
- 同一账本继承历史 71 次调用和剩余 65 次。首轮／第二轮各上限 12，整体上限 20，发现具体问题时才动用 21 次余量。完整单元先预约；失败／未知计入消耗；旧五次第三周期记录用哈希锁定，不修改旧 attempt 或 stopReason。相同轮次样本拒绝重复；第二轮需新冻结版本或固定资源变式。
- 准入前使用全局训练锁、在线队列检查和有界旧请求查询。旧已取消请求的 interrupted 保留；旧未知 ephemeral thread 已不可读取，形成独立新任务的隔离判断，旧状态和用量仍为未知。接口异常、活动迹象或新未知请求不放行后续派发；没有重发旧请求。
- 时间由预算账本控制，provider 不再叠加固定 180 秒。区分首个实际输出、实际输出增长后的停流、单请求上限、总任务上限及用户取消。确认／usage 事件不能延长停流期限。嵌套训练继承同一 signal，超时原因与用户取消分别保留。
- 讲解采用 90 秒诊断观察点；它不自动杀进程。片段制作总上限 10 分钟、单请求上限 5 分钟；完整制作按体量估计总额度，单请求上限 12 分钟。2–5 分钟和讲解 30–60 秒仍是响应目标，不是保证。
- 浏览器只对本标签页提交的请求，在合格回答已绘制且可见之后写入 `tutor:readable:<turnId>` performance measure 和 `tutor:readable-response` 事件。provider 首个事件、原始 JSON 和恢复历史不计作回答。该测量是本机浏览器观测，不上传外部遥测。
- `pause` 文件信号／SIGINT／SIGTERM 传到当前请求，provider 尝试 interrupt 并短暂等待终态，保存部分输出和已报告 usage；interrupt 确认不冒充远端停止。ResearchPlans 新增外部取消信号。停止后不自动续发。

## 验证与使用

生产构建和 202 项自动测试通过；新增检查覆盖连续输出、真实停流、首输出期限、总时长、取消、嵌套账本、来源范围 ID、四次调用上限、历史保护、补原文的两种分类及完整稿实际图像输入。四组零调用浏览器检查通过：实际可读响应计时、三核心／完整稿、研究方案及配图裁剪。模拟回答约 1.06 秒只是浏览器测量流程证据，不代表真实模型速度。

```powershell
npm.cmd run training:short -- prepare                # 零调用，冻结新版本
npm.cmd run training:short -- status
npm.cmd run training:short -- run intervention       # 新样本，先准入与预约
npm.cmd run training:short -- run protein round-2    # 固定资源变化
npm.cmd run training:short -- pause                  # 优雅暂停
npm.cmd run training:short -- admit                  # 有界核实后允许新的明确派发
npm.cmd run training:short -- verify <记录ID> <证据JSON>
npm.cmd run training:short -- crop <原记录ID> <选区JSON>
npm.cmd run training:short -- edit <原记录ID> <手改JSON> # 同页备注／完整稿，最多四次
npm.cmd run training:short -- whole ppt              # 局部质量／实际文件通过后
npm.cmd run training:short -- whole plan
```

已运行的样本不能自动重发。`verify` 的证据 JSON 需有 runId、freezeHash、findings、sciencePassed、filePassed，以及全部实际 artifact 的 path／hash；它记录人工走查，不能当作自动独立科学审查。crop 文件使用最多两项 edits：slideIndex、region（left／top／width／height）及可选 notes；沿用原图，增加核对调用，仍计同一周期。edit 文件最多两项 edits，每项须有 slideIndex／notes，并可提供整份 speechScript；可选 question 限定实际改稿意图。显式新输入和失败后的普通保存建立新版本，不能续发旧 attempt；未核对或阻断版本继续拒绝导出。整体修复复测须已绑定失败走查及新冻结实现，不能同稿空跑。

用户继续使用三个现有核心入口。内部入口没有新增用户端训练界面；本轮不发布新教学规则。讲解交互目标尚未达成，应根据实际冗余和核对必要性继续定位，不能只靠扩大期限称为提速。
