# 整体方案实施验收

依据：`Skill与工作流驱动的科研学习助手_落地方案.md` v1.0。2026-10-05 本机 07:00 启动；定时任务已停止，避免重复启动。以下分别记录已实施能力、工程检查和实际行为。

## A：标准 Skill 与学习模拟

十个入口均含标准 YAML 名称与触发说明，保留原 ID 与 manifest 兼容旧入口。发现目录只提供名称和描述；后台按任务加载正文，引用限定在对应包内，正文及入口变化进入版本哈希。仍由后台加载，没有声称已启用模型原生自主读取或联网。格式依据 [Agent Skills 规范](https://agentskills.io/specification)。

新增独立学习模拟，保存画像版本、概念状态、真正可见的讲解、实际作答和证据编号。讲过、自述理解及表现为能应用分开记录。评分规则与答案留在验证端；学习者视图只含自己的状态、所见讲解、历史题目与回答。保存后可以恢复同一学生，更换学生不共享状态。失败、未见引用、取消和保存失败不会产生掌握证据。

工程：构建及 54 项测试通过；skill-creator `quick_validate.py` 对全部十个入口通过。验证器的 PyYAML 仅装入忽略的 `runs/skill-validator-lib`，未修改系统 Python。

真实回放：`npm run learner:check -- --live`，GPT-6.1 Sol，与旧试读基线使用同模型和同一缺前提讲解。报告 `0295c457-2d84-4c20-98c3-0d6119767ef2` 保存于 `data/simulation-reports/`，独立学习者输入输出在 `data/simulation-attempts/`，状态在 `data/learners/`；这些运行数据不提交。

| 观察 | 实际结果 |
