## 新接口

```http
POST /api/conversations
{"paperId":"xu-2018","profileId":"beginner"}

POST /api/conversations/:id/messages
{"clientMessageId":"figure1-report","mode":"live","question":"帮我读懂 Figure 1，解释相关方法，再整理成三页汇报。"}

GET /api/conversations/:id
GET /api/turns/:id
POST /api/turns/:id/cancel

PUT /api/conversations/:id/progress
{"version":3,"unitId":"已交付的教学 run ID","state":"confused"}
```

`messages` 返回 202 和轮次 ID，`turns` 返回计划、预算、进度、已确认内容、文件链接及具体待处理问题。`version` 使用最近读取的会话版本。独立方法可不传 paperId；读图与论文汇报需绑定论文。`exportRunId` 可直接导出当前会话、同来源版本的已核对大纲，零生成。旧 `/api/tasks` 继续返回原 TaskRun 结构；可选传 conversationId 和 clientMessageId。
