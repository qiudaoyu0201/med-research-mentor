# 研究工作台首轮实施验收

日期：2026-10-05。依据：《论文研究工作台与 PPT 专区落地方案》v1.2。交付范围：A 与 B1 的核心阅读流程。

## 已实现

- 首页以“导入论文”“说说你的研究想法”为起点，真实数据与请求接入默认路由；固定原型单独保留在 `/prototype`，既有教学与 PPT 工具保留在 `/assistant`。
- 课题创建、重命名、归档／恢复；论文显示名称与归组保存在独立元数据索引，移动保留论文 ID、原始标题、来源版本与成果。旧论文默认未分组，旧会话与个人学习记录继续保留。
- 点击与拖入共用 PDF 校验：一个文件、30 MiB 上限。前后端拒绝不支持格式和伪造内容；真实 PDF 继续由解析器验证，扫描件、损坏件保留实际材料状态。图片入口明确显示尚未开放。
- 导入后立即展示当前来源版本的摘要／研究描述／正文摘录和最多三个规则问题。无可用正文时提供补充动作；未登记图件时不推荐虚构图件。
- 自然问题进入既有连续对话，复用调用预算、取消、核对与一次修订。首次问题生成讨论标题，用户改名后保留名称；论文恢复最近讨论，也能开始新讨论。
- 原文来源锚点包含论文 ID、来源版本、来源 ID、片段和页码，后台核对文字归属；回复选句沿用 `focus`。已登记图件通过服务端来源 ID 获取原图。点击追问只预填输入框，不直接发模型请求；切换论文立即清除引用并恢复各论文草稿。
- 来源按需在右侧展开；手机可通过段落按钮提问并返回讨论。笔记保存已完成回答、原讨论、原来源版本和文本依据，重复保存保持幂等。可编辑名称／正文、返回原讨论、导出 Markdown；编辑保留依据并拒绝旧版本覆盖。
- 后台持久化当前材料、讨论和阅读面板，刷新或重启后恢复；尚未提问的导入论文也有当前上下文记录。

数据索引保存到 `data/workspace/index.json`；论文、会话、运行与个人反馈沿用原目录。测试采用 `runs/workspace/` 下的隔离数据目录，个人材料和测试产物均不加入 Git。

## 尚待实施

- B1 的模型生成轻量概述、可取消任务与版本化缓存；当前使用有真实来源的摘录和规则问题。PDF 文字层直接选取仍未接入，当前选句基于提取正文。
- B2：PNG／JPEG 独立导入、解码、科研用途准入、用途补充、单图重试与连续补图。
- C：独立 PPT 创建工作区、时长／重点设置、汇报命名与关联、页面／讲稿／引用预览。现阶段入口接现有工具，其单页修改、版本恢复和导出能力保持原行为。
- D：目标用户试用；真实科研图片准入与所有图件类型尚未验证。历史内容核查失败和 Figure 1m 分母依据缺口保留。

开发时多套 Vite 服务并行曾产生热更新连接报错；关闭测试服务、改用正式构建后完整浏览器检查通过。曾发现的切换论文引用延迟与快速刷新面板未保存已修复并复测。
