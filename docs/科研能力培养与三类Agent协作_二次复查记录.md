## 3. Agent 配合的最终核对

### 3.1 助手的产物能力

大模型已有能力与经核查的成熟 Skill、多论文案例 → 助手生成方案／PPT → 校验直接检查科学依据、设计／叙事、文件 → 按原因修改产物或规则 → 回归、留出与范围明确的发布。

PPT 的代表性质量案例加入：学过内容的小白试讲与追问、初始听众可跟随性 → 校验结合实际页面及行为定位质量问题 → 助手改页／讲稿 → 同等条件复核。讲述顺畅不能抵消事实或视觉错误，讲不清也不自动归咎 PPT。

### 3.2 教学与迁移能力

助手使用有效能力进行多论文教学 → 小白实际学习和提问 → 新课题独立方案／新条件独立组织 PPT → 校验原稿、适配、理由和未知 → 反馈助手补教或调规则 → 同题纠错／未见题再迁移。

目标课题助手答案仍隔离。试讲已有 PPT 是理解与质量诊断；独立组织是另一种行为。两者可以共享相关材料和证据机制，不共享同一个成功结论。

### 3.3 校验与助手交流

反馈有位置、依据、影响对象、根因与把握、改什么和怎样再验证。助手按反馈处理材料、教学、设计、页面或模拟规则；校验不强行归因。完整评分输入留在核对侧，公开补教摘要不泄漏隐藏答案。校验自身的准确性另验，固定事实与评价不能被候选自行改写。

### 3.4 用户使用

主体提供理解帮助，研究方案／PPT 默认助手加轻量核对，首轮 2、含一次修订 4。需要理解／讲述诊断时增加一种小白条件，3／6；现有核心教学轻量试读仍如实保留。用户不默认跑内部双条件、前后测、留出或大规模训练。

### 3.5 可选演讲稿融入两条闭环

现有 shared/types 的 Slide.notes、PPT 页内展示／编辑及现有 PPT Skill 已有逐页讲稿基础。本轮新增规格是可选完整稿，不宣称功能已经实现，也不泛称所有上游 Skill 都具备。用户可随 PPT 生成或对指定版本补写，按时长／听众／场景组织开场、逐页讲述、转场和结尾；备答单列。

助手联合生成页面与稿件、校验一致性、小白按明确辅助条件试讲、反馈改页／改稿属于产物质量闭环。独立组织任务隔离对应助手稿件，受助读稿不当独立迁移。新增 SpeechScriptVersion、页面关联、同步／失效与导出合同，F04／F06／F07 和 T46／T47 一起承接，正文 10.5、12、13 已融入。

同次生成不强制另拆模型调用：助手＋联合校验基础 2，完整修订 4；对已有 PPT 补稿新增 2，累计根账本。长稿拆分、额外审阅和失败仍计调用、用量和截止，不能隐形超额。

每条路径的准备、教学、模型视觉审阅、新追问、校验校准、失败与候选都另外计账。程序渲染不算模型调用，但模型审阅渲染图算。复用页面或已有行为不重算生成，新增综合校验仍算一次。

原示例基础为 8＋12＋8＋4＋1＋8＝41；指定四次补教再加 12＝53。它只含一个明确类型的留出，不能声称两类留出齐全。若同时检查方案与 PPT 留出，留出由 8 改 16，基础为 49；开发 PPT 基线／候选已有直接核对，再补双条件各 3，共加 6，得到 55，剩余 9 次。不能再同时塞入全部 12 次补教。

不足时保持本批范围，必要检查未运行列未验证；新批次须有明确预算，自动继续不能清零绕限。发布依据执行清单与实际证据，不依据预算表数字。

## 5. 全局复查范围

- 产品目的与双线学习：继续帮助医学生形成研究思路和方法能力，不因新增两个专区偏离教学。
- 内部与用户：内部采用多论文积累、分别评价，线上轻量使用；单篇例子与小批次不称普遍迁移。
- 角色与输入：只有三类角色，汇报者／听众为小白模式；协调、渲染、版本管理是程序。
- 证据与版本：原稿、辅助条件、试讲、来源和报告版本关联；事实、产物质量、学习、真实效果分开。
- 前后端：并列入口、无 PDF 起步、多来源、分节编辑、状态恢复与导出都已有合同；新的诊断目的、阶段和可选演讲稿条件／版本也进入合同和缓存。
- 调度与停止：全局两槽、前台优先、资源锁、幂等、根账本、部分状态和停止后收益规则一致。
- 视觉与质感：13.4 的 iOS 材质、层次、字体、控件与动效要求保留，长文、浅深色和真人验收不被装饰替代。
- 国内模型与历史：通用接口不代替国内实测；历史 Figure 1m／三页 PPT 问题、真实渲染和真人体验待办保留。
- 实施依赖：在线生成基本路径与内部平台分阶段落实，F04／F05／F06 同步接入试讲反馈、归因、校准和复合账本；没有只补前端按钮。
- 来源与比赛：本次未重新读外部通知／上游，不把历史核查称作新验证；正式报名仍需确认通知和实际能力。
