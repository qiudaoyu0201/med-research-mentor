# 医研导师：资料、成果与回退管理落地方案

## 1. 目标

解决当前使用中的几个核心问题：导入的论文无法移除，PPT 和研究方案生成后难以管理，生成失败后需要重复填写，正在生成时缺少明确的取消路径，历史成果选择入口不直观，以及清理资料时可能误伤已有成果。

本方案遵循一个原则：**左侧负责创建和管理，右侧负责当前工作；资料可以被成果引用，但资料与成果不互相绑死。**

## 2. 界面总结构

系统保留三个独立专区：论文带读、PPT、研究方案。每个专区拥有自己的左侧栏，不把三类对象混在一个列表里。

### 2.1 左侧栏：创建与管理

左侧统一放置：

1. 新建或导入入口；
2. 搜索框；
3. 课题分组；
4. 当前专区的对象列表；
5. 对象的重命名、移动、归档等管理菜单。

点击左侧对象后，右侧打开其内容。左侧项目代表一份论文、一个 PPT 成果或一份研究方案；成果的历史版本不拆成大量左侧项目。

### 2.2 右侧：当前工作

右侧根据对象状态显示不同内容：

- 论文带读：阅读区、PDF 对照、图表查看、对话和追问；
- PPT：来源选择、要求填写、生成状态、幻灯片预览、逐页编辑、版本和导出；
- 研究方案：研究问题、限制条件、参考论文、生成状态、正文、版本和导出。

生成前显示准备区，生成中显示任务状态，完成后显示成果操作；不把所有按钮同时堆在页面上。

## 3. 三类对象的职责

### 3.1 论文资料

论文是可复用的原始资料，包含 PDF、解析文本、图表、来源定位、论文带读记录和必要的解析缓存。

论文可以：

- 导入；
- 重命名；
- 移动到课题；
- 归档；
- 从回收站恢复；
- 在设置中彻底删除。

删除论文不会删除已经完成的 PPT 或研究方案。它只会使该论文不再出现在新成果的来源选择器中，并在引用它的成果中显示“来源已归档或删除”的提示。

### 3.2 PPT 成果

PPT 是独立成果，可以由一篇论文、多篇论文或一次新的汇报任务生成。当前版本和历史版本属于同一份成果，放在右侧的版本区管理。

PPT 可以：

- 新建；
- 选择已有论文或导入论文；
- 填写汇报要求和页数；
- 生成；
- 取消生成；
- 对已有版本提出修改要求；
- 生成新版本并保留旧版本；
- 失败或取消后重试；
- 导出；
- 归档或删除。

### 3.3 研究方案成果

研究方案也是独立成果，不归属于某一篇论文。它可以选择一篇或多篇论文作为参考，也可以先从研究想法、条件和限制开始。

研究方案可以：

- 新建；
- 选择或导入一篇或多篇论文；
- 填写研究问题、资源、限制和预期目标；
- 生成方案；
- 取消生成；
- 修改要求并生成新版本；
- 失败或取消后重试；
- 恢复历史版本；
- 导出；
- 归档或删除。

## 4. 来源关系：有主线，但不强绑定

为了保留论文带读、PPT 和研究方案之间的连贯性，成果创建时记录来源关系，但不把成果永久绑定到某一篇论文。

### 4.1 PPT 的来源

从论文带读进入 PPT 时，当前论文自动加入来源；从 PPT 专区新建时，可以选择一篇或多篇论文，或导入新的 PDF。

界面明确显示：

```text
当前 PPT
主要来源：论文 A
补充来源：论文 B、论文 C
```

通常一篇论文作为叙事主线，其他论文用于补充背景或比较。更换主要来源时提示用户建议另存为新版本，避免无意破坏原有结构。

### 4.2 研究方案的来源

研究方案允许多选论文。来源区分为主要参考和补充参考，但不要求所有方案都必须有主要论文；用户可以先输入研究想法，再补充文献。

### 4.3 来源副本

每个 PPT 或研究方案必须保存实际使用过的必要来源和图片副本，不能只保存一个指向论文库的链接。这样即使原论文被归档或彻底删除，已有成果仍可以正常查看、编辑和导出。

成果中的来源状态包括：

- 来源正常；
- 来源已归档；
- 来源已删除，但成果保留了使用副本。

## 5. 新建、编辑、取消和重试

### 5.1 新建入口统一放左侧

- 论文带读：左侧“导入论文”；
- PPT：左侧“新建 PPT”；
- 研究方案：左侧“新建方案”。

点击新建后，左侧立即出现一条草稿记录，右侧打开准备区。草稿自动保存，用户可以暂时离开后继续填写。

### 5.2 编辑已有成果

已有成果通过“修改要求”生成新版本，旧版本继续保留。例如：

```text
第 1 版：初始汇报
第 2 版：补充实验设计和对照
第 3 版：压缩文字并调整讲述顺序
```

版本名称、创建时间、修改要求和来源快照都应保留。用户可以打开任一版本、恢复为当前版本，或以它为基础继续编辑。

### 5.3 取消生成

生成中的任务显示“取消生成”。取消后：

- 后端任务停止；
- 已有旧版本保留；
- 当前输入的要求保留；
- 页面显示“重试”和“修改后重试”；
- 迟到的任务结果不能覆盖当前选择的版本。

### 5.4 重试

失败或取消的任务保留原始输入、来源和生成选项。点击“重试”直接复用这些内容；点击“修改后重试”先进入可编辑状态，修改后再提交。

## 6. 归档、恢复与彻底删除

日常操作默认使用“归档”，不直接永久删除。

### 6.1 归档

归档对象从正常列表和新建时的来源选择器中隐藏，但资料、对话、成果、版本和来源副本都保留。归档后的对象可在设置中的归档管理区恢复。

### 6.2 恢复

恢复后对象回到原专区和原课题分组，原来的阅读记录、版本和来源关系一起恢复。

### 6.3 彻底删除

彻底删除只放在设置中的归档管理区，并在操作前显示影响范围：

- 删除论文：删除 PDF、解析缓存和论文带读资料；已有成果保留来源副本；
- 删除 PPT：删除该 PPT 及其所有版本，不影响论文和研究方案；
- 删除研究方案：删除该方案及其所有版本，不影响论文和 PPT。

永久删除后不提供普通恢复，因此需要二次确认。当前阶段不设置日常“清空全部”按钮，避免误操作；用户需要重新开始时直接新建对象。

## 7. 左侧对象菜单

每条左侧记录使用统一的“…”菜单。日常菜单包括：

- 打开；
- 重命名；
- 移动到课题；
- 归档。

成果对象还可以显示“查看来源”。恢复和彻底删除只在设置的归档管理中出现，避免日常操作区过于拥挤。

## 8. 状态与异常处理

所有论文和成果都应有明确状态，避免用户不知道当前能做什么。

| 状态 | 右侧可用操作 |
| --- | --- |
| 草稿 | 继续填写、保存、生成、归档 |
| 生成中 | 查看进度、取消 |
| 已完成 | 查看、编辑、另存新版本、导出、归档 |
| 已取消 | 查看原要求、重试、修改后重试、归档 |
| 失败 | 查看失败原因、重试、修改后重试、归档 |
| 已归档 | 在归档管理中恢复或彻底删除 |

失败信息要说明是网络、模型、来源解析还是内容核验问题；不把“重新生成”当作唯一出口。

## 9. 视觉与交互要求

1. 左侧列表保持稳定宽度，支持搜索和课题折叠；右侧保留主要阅读和编辑空间。
2. 左侧选中项有明显但克制的状态，不使用过大的卡片占满空间。
3. 长标题截断显示，悬停或详情中显示完整标题。
4. 生成、取消、重试、归档等状态使用统一按钮样式和文字。
5. PPT 和研究方案的成果选择使用独立的列表或卡片区，显示名称、版本、时间、状态和来源数量，不再依赖一个拥挤的下拉框承载全部成果。
6. 来源变化、删除影响和版本恢复都用简短提示说明，避免用户猜测。
7. 切换专区或对象时保留未提交草稿、当前页码和阅读位置。

## 10. 实施顺序

### 第一阶段：资料和成果可管理

1. 增加论文归档、恢复和彻底删除接口。
2. 增加 PPT 成果归档、恢复和删除接口。
3. 补齐研究方案版本和任务记录的统一删除边界。
4. 为对象增加明确的状态和回收站标记。

### 第二阶段：左侧列表和右侧工作区

1. 重构三个专区的左侧列表。
2. 将新建、导入、搜索、课题分组放到左侧。
3. 将来源选择、要求、生成、取消、重试、编辑和导出放到右侧。
4. 将 PPT 和研究方案的历史版本收进右侧版本区。

### 第三阶段：版本与来源可靠性

1. 为 PPT 和研究方案保存来源快照及必要图片副本。
2. 实现修改要求生成新版本，旧版本可查看和恢复。
3. 实现取消后保留输入并可重试。
4. 增加来源归档或删除后的提示。

### 第四阶段：回归验证

至少验证以下流程：

1. 导入论文、归档、恢复、彻底删除；
2. 删除论文后，已有 PPT 和研究方案仍可打开、编辑和导出；
3. 新建 PPT、取消、重试、修改后生成新版本；
4. 新建研究方案、选择多篇论文、修改、恢复历史版本；
5. 删除一份 PPT 不影响论文带读和研究方案；
6. 切换专区后草稿、阅读位置和当前版本正确保留；
7. 迟到的后台结果不会覆盖用户当前选择的成果。

## 11. 完成标准

用户应该能够在不依赖猜测的情况下完成这条路径：

```text
左侧新建或选择对象
→ 右侧选择资料并填写要求
→ 生成、取消或重试
→ 编辑并保留新版本
→ 归档不需要的对象
→ 在设置中恢复或彻底删除
```

论文带读、PPT 和研究方案各自保持清晰的工作空间，同时通过来源关系互相衔接；删除、取消、重试和版本恢复不会再互相误伤。
