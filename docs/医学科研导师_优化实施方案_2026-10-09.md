# 医学科研导师优化实施方案

依据：[54 条需求访谈基线](医学科研导师_需求访谈基线_2026-10-09.md)。用户已于本轮授权实施。本文是执行方案，完成状态只在验收记录中更新。

## 目标和取舍

核心为医学科研导师式带读，PPT／研究方案为独立的一次生成专区。保留来源、任务、版本、取消、数据恢复后端；主界面去除编辑器、专门笔记、学习评分和内部角色状态。所有旧资料原样保留；历史产物继续提供查看和下载。新首页不自动打开上次论文，但显式选择历史论文后恢复聊天。

## 实施顺序与合同

1. **教学和阅读体验（T01–T20、R01–R11、U01–U07）**：安全 Markdown 支持段落、列表、强调、表格，不执行 HTML；引用追问校验实际可见文字与所属已完成回答。图表／来源入口靠近相关解释。提供当前来源的按需中英对照，缓存按论文、来源内容、模型和规则绑定；失败可显式重试，切换来源不会覆盖当前内容。首次背景介绍后进入正文；后续以句段边界组合连续原文，保留字符范围核验。无范围目标答案不冒充全文总结。
2. **偏好和轻记忆**：增加服务端导师默认设置；新会话继承，现有会话不被全局修改覆盖。自然语言泛指程度调整持续生效，明确局部／选区要求仅当前生效。跨论文只继承已讲术语的轻量摘要，不宣称掌握，不带入其他论文事实。
3. **联网辅助**：后端复用受控 PubMed／Crossref 服务，由问题与材料缺口决定是否检索；英文化检索式与调用计入当前预算。外部摘要和元数据明确标记，不伪装论文原文或全文。不让模型任意操作浏览器、shell 或文件。失败时保留当前论文教学能力和具体检索限制。
4. **生成专区（P01–P09、S01–S07）**：PPT 选择已有／新导入论文，选填汇报要求和页数，系统自动材料选择；单独汇报会话，不扰动带读进度。预览、取消、下载可用；讲述提示由已核对页面 notes 确定性另行导出，不写 PPT 备注。方案填写问题、条件、自由要求、可选参考论文；默认检索和完整稿，按医学研究类型组织；提交一次完整生成、显式重试或新任务，不显示编辑、恢复和逐节修改工作台。
5. **提供方与内部迭代**：真实检查入口使用统一提供方工厂，Codex 默认保持可运行；国内模型需另外实测。继承三角色、材料快照、基线／候选、开放作答、留出与成本记录。按本次教学要求更新 Skill 候选，分别验证讲解、PPT 和研究方案。自主启用仍须比较证据及回归通过；旧未知请求状态和账本保留。真实模型不可用时如实记录阻塞，不用 fixture 声称模型效果提升。

## 验证与交付

- 单元／集成：Markdown 引用归属、局部与持续偏好、新会话默认、来源翻译缓存与并发、取消、检索失败、生成专区幂等和历史下载、讲述提示不进入 PPT。
- 工程：TypeScript、生产构建、完整自动测试；新入口独立浏览器验证，不写日常用户数据。不为适配旧产品需求而把有意移除控件重新加回。
- 浏览器：桌面不同宽度、浅深色、长回答、引用输入、来源展开／返回、生成／失败／重试／下载。截图和真实导出分别检查，模型产物与固定响应证据区分。
- 实际内容：在可用模型上固定医学案例记录调用、输入、结果和耗时；与旧规则对比后再判效果。不同医学类型分别记录覆盖，不以单例代替全医学验收。
- 参赛：Word 设计说明不超过 5000 字；3–6 分钟视频需要真实运行素材；支撑材料列实际证据。当前模型与拟迁移国内模型分别写明，不能把迁移计划写成完成。
- 每批在 main 审查最终差异、验证后提交；只提交本任务更改，不推送、不改写历史。最终交付列需求 ID、完成证据、未完成项和真实调用限制。

## 明确限制

不建设账号、云部署、手机端、诊疗服务、实验结果分析平台或完整办公编辑器。网络文献阅读层级、PDF 定位失败、模型生成失败必须如实呈现。保留迭代的评价约束，同时避免把所有内部记录和警告倾倒到用户正文。真正的真人学习效果需后续用户体验，不由模拟成绩代替。
