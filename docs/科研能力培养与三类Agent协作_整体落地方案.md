## 1. 要做成什么

下一阶段的具体顺序、累计约束和评价／预算细则见[自主迭代 v1.5](用户使用质量与自主迭代_落地方案_v1.5.md)。本文第 4 节继续保留产品依赖与原关闭条件，历史验收不被新方案覆盖；v1.5 目前仅文档落地。

让医学科研初学者简单、快速地使用三个核心能力：**论文讲解、论文 PPT 生成、研究方案生成**。用户可以只解决眼前的问题，不必完整读完论文、完成课程或通过考试。

| 核心能力     | 用户需要的结果                                             | 正常路径                                               |
| ------------ | ---------------------------------------------------------- | ------------------------------------------------------ |
| 论文讲解     | 看懂研究问题、设计理由、方法和证据，能继续追问             | 导入材料或提出问题 → 讲解 → 按需查看原文、追问、记笔记 |
| PPT 生成     | 能实际汇报的页面、论文配图、逐页讲稿；按需提供完整演讲稿   | 选择论文 → 生成 → 查看、修改、保存 → 导出              |
| 研究方案生成 | 适合当前问题和资源的方案草稿，说明做什么、为什么、未知条件 | 输入问题 → 生成 → 补条件、修改、保存 → 导出            |

笔记、附件、来源、偏好和历史版本继续服务这些路径。保留现有布局和整体平衡；常用操作直接可达，辅助内容按需展开。内部角色、账本、评测和依赖管理留在程序及开发侧。

## 2. 已确定的边界

- 不建设用户端“研究方案转 PPT”，也不建设跨产物自动回写或复杂同步界面。
- 阅读器保留手动框选图片、段落和查看原 PDF。**不做逐条讲解的自动截图、识别和卡片匹配。** 选区可大可小，由内容决定，不强制裁成窄条。阅读选区仍按阅读场景保存；PPT 编辑器直接选择原图或 PDF 原页并裁剪，不自动串联两处草稿。
- **论文图件进入 PPT 的产品链路已实现。** 普通 PDF 根据图注和绘图几何定位原图；生成请求实际带入图件；PPT 内可替换、框选、保存版本及导出。两篇真实论文的图件与文件链路已检查，真实生成效果另外验收。
- PPT 配图优先复用原论文的图件和已有渲染能力；必要时准确裁剪，保留轴、图例、面板标签、比例尺等理解证据所需信息。范围较大时保留大范围；不新增独立素材管理专区。导入时缓存图件预览，生成／保存时只为采用的图件生成高清资产；不调用视觉模型逐页截图识别。定位不可靠时保留 PDF 原页和手动裁剪，不声称所有版式都能自动提取。
- 生成、取消、补材料／条件、修改、保存、查看来源和正常核对都保留。取消只结束当前任务，已有产物和草稿保留；仅在有未保存修改时提供必要的放弃入口。
- PPT、研究方案只允许成功完成当前核对的保存版本导出。失败、未核对或有阻断问题时不可导出；草稿保留供修改。普通警告和未知条件如实保留，不引入“带问题导出”模式。这里的成功指当前轻量核对完成，不代表科学结论已独立证实。
- 手动修改稿须按当前内容核对；恢复的研究方案会失去旧核对，需要重新核对。当前 PPT 恢复的是同源、同内容的已完成旧版，保留其原核对；不能将恢复过程描述成已经重新调用模型核对。
- 完整演讲稿留在 PPT 原有区域，支持生成、补写、编辑、保存以及 Markdown／TXT 导出；逐页讲稿和 PPT 备注保留。修改页面后，新版本不沿用不匹配的旧完整稿。

## 5. 内部迭代保留的目标

下一阶段执行[用户使用质量与自主迭代方案 v1.5](用户使用质量与自主迭代_落地方案_v1.5.md)：由执行者自主发现、实现和评价，用户可随使用反馈，不承担测试组织或技术选择。优先处理已有内容缺口、理解／返工负担和实际等待，采用固定新任务及同模型合理简化流程对照；科学、解释、文件、内部操作走查与真人效果分别报告。累计用户要求继续有效，不增加用户界面的内部管理步骤。

v1.5 本次只落地文档，预算扩展、代码和新评价尚未实施。原账本累计 108 次、第三周期剩余 28 次；用户允许增量并授权自主取舍，本方案安排新增 30、下一阶段最多 58 次，先最多 20 次复核收益，其余按具体问题决定。后续先实现同账本的扩展与接续分路一致校验，保留历史、未知及旧发布结论，不另开额度或第四候选。独立人员未参与的走查明确为内部评价，真人学习与正式候选门槛仍保留。

固定助手、小白、校验三类角色，不增加用户需要理解的角色或后台工作台。

- 助手产物能力：根据真实材料生成讲解、方案、PPT 和讲稿；校验直接检查事实、设计、表达和最终文件；小白诊断理解断点，反馈具体修改后再检查。
- 教学迁移能力：保存实际可见教学和状态，在未见目标答案的新情境中独立解释、设计或组织汇报；区分受助表现、同题纠错、再次迁移和真人长期效果。
- 材料与规则：按已确认缺口积累多论文、方法、基础原理和反例；内部 paper-lookup 尚未接入。首次能力包可用手选核对材料，不要求先完成自动采集平台。
- 有界磨合：记录实际调用、来源、版本、失败和改动；分别比较产物质量与教学效果，候选通过必要回归和留出后才成为有效能力。

这些是内部第一轮的待实施目标，不是当前产品完成证明。阶段、角色输入、案例分组、调用边界、验收和有效规则启用以[第一轮实施细则](内部训练第一轮_落地方案.md)为准。细化合同与历史 F01–F11／T01–T62 设计留在[v2.5 内部规格归档](科研能力培养与三类Agent协作_整体落地方案_v2.5归档.md)，实施时只取与当前任务有关且不违背本文边界的部分，不把整套规格搬进用户界面。

## 6. 如何验收和报告

| 证据层                             | 能证明什么                             | 不能代替什么               |
| ---------------------------------- | -------------------------------------- | -------------------------- |
| 类型、单元测试、固定响应浏览器检查 | 接口、状态、保存、取消、版本和操作流程 | 模型科学质量、真实用户效果 |
| 真实生成与原文对照                 | 指定材料与请求下的内容和用量           | 所有论文／研究类型均可用   |
| 实际 PPTX 渲染、稿件和导出检查     | 最终产物的图文、排版、来源和版本一致性 | 真人试讲和投影效果         |
| 目标用户完成真实任务               | 可发现性、阅读体验、任务完成和实际困难 | 长期学习收益或广泛推广效果 |
| 固定条件比较、留出与独立行为       | 指定范围的候选改进和迁移证据           | 未验证场景和长期保持       |

每次交付明确写：改了什么、在哪个入口能用、实际验证了什么、还缺什么。状态分“已实现”“部分完成”“待实施”“未验证”；已定位缺陷只能在修复并复测后关闭。文档修改、截图存在、HTTP 200 和模型自评都不能单独作为产品效果通过。
