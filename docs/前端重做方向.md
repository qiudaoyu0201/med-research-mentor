# 前端重做方向

2026-10-04，根据用户提供的 Codex 深色工作区截图确定整体方向。

页面采用左侧导航、中间对话、右侧内容面板的结构。左侧组织论文和历史会话；中间连续呈现问题与讲解，底部固定输入框；右侧按需展开原文、图件或 PPT 编辑器。论文带读、方法、图表和 PPT 作为同一会话里的操作入口。

视觉采用深色底、细分隔线、克制的圆角与蓝色强调。减少首页宣传标题、大卡片和重复提示，把主要空间留给对话与阅读。先验证对话页、PDF 联动和 PPT 面板，再统一设置与记录的样式。

本轮先完成界面文案清理。布局与深色视觉按上述方向重做。

写作参考：[anti-defensive-writing 中文规则](https://github.com/Kiterlin/anti-defensive-writing/blob/main/skill/anti-defensive-writing/SKILL.md)。直接说明动作和结果；删除重复免责、预先辩解和没有信息增量的澄清。资料信息放在设置中，任务问题和检查结果按需查看。

交互参考：[assistant-ui](https://github.com/assistant-ui/assistant-ui) 的对话组件，以及 [PaperSuper](https://github.com/EricEvans-e/PaperSuper) 的 PDF 工作区。本项目根据现有功能独立实现。
