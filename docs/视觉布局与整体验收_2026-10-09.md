# 视觉与整体验收迭代记录（2026-10-09）

## 已落实

- 讲解 Markdown 根节点改为正常空白处理，避免 React Markdown 的块级换行叠加选择器的 `pre-wrap`；代码块仍保持预格式。
- PPT 使用内容驱动的可编辑布局：图文页采用大图加右侧解释；三步路径采用横向三列；四条及以上要点采用两列；短内容保持单列。统一字号并按整列测量高度，无法容纳时明确要求精简。
- PPT 页面和 PPTX 导出共用同一布局计算；编号标记是独立可编辑文本，讲述提示仍单独下载。
- 参考了 GitHub 的 [github-markdown-css](https://github.com/sindresorhus/github-markdown-css)、[PptxGenJS](https://github.com/gitbrent/PptxGenJS)、Slidev 的 [two-cols](https://github.com/slidevjs/slidev/blob/main/packages/client/layouts/two-cols.vue) 与 [image-right](https://github.com/slidevjs/slidev/blob/main/packages/client/layouts/image-right.vue) 布局思路，没有复制主题或引入新依赖。
