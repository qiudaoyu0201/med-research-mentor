# 内部训练第一轮：周期 2

2026-10-07。周期 1 的原账本与未知调用保持原样；本周期重新冻结一个共享规则候选，不拼接旧答案，不自动重发。前序已消耗 28 次尝试，计入同一首轮 108 次产物预算；最多剩余 80 次。M3 仍单独最多 36 次，不因产物比较不完整而启动。

## 本次改动与验收

候选只修改共享规则的反馈整合层：解释必要术语与测量到推理的连接；新手反馈要求补理解桥梁，不删关键概念；核对反馈先判断是否影响当前目标，不扩成未请求的专业操作手册。已有可见来源支持的原理必须解释；确有证据限制时说明其影响，避免反复叙述工作状态。只生成当前请求的产物。

基线与候选使用相同的工程修复：普通讲解的意外 deck 在首次生成、修订和缓存路径排除，随后角色不查看该 PPT，交付层也不保存或导出它。内部训练由独立案例主动请求三类产物；正常用户只核对实际请求的功能。

独立评价分别检查事实、解释完整性、可理解的推理和范围。缺项、无效位置或无效来源是评价无效，不能冒充正确拒绝；事实核对必须给实际来源。六份校准中包括准确但省略必要理由的短答案，以及图文错误、术语堆砌和工作记录泄漏。

开发候选 D1 若仍有关键质量失败，不进入后续与留出比较，先保留证据定位原因。成本记录包括实际尝试、失败／未知、报告的 token、缺失用量、provider 累计时间和输入字符；缺失 token 不记为零，不推算订阅现金费用。记录的 CPU／峰值内存只覆盖训练 Node 进程，不代表整机或远端服务负荷。默认串行，不扩大在线并发，不删除必要核对来换取表面效率。

工程回归包括意外 PPT 不进入后续角色、修订或缓存交付，正常 PPT 原路径仍通过；前序未知调用计入额度、并发前序与重复账本拒绝；无效事实评价不算校准通过。精确结果和调用以运行后记录为准。

## GitHub 学习与具体采用

查阅 [DSPy GEPA 官方文档](https://github.com/stanfordnlp/dspy/blob/bc8af7ed3d5ee0b892211e5c03274396442a413c/docs/docs/diving-deeper/gepa-in-depth.md)：具体失败反馈比单一总分更能支持候选修订，组件修改和逐例结果应可追溯。本项目沿用一个共享层候选，保留逐项位置、理由、输入和候选快照；不安装优化器，也不采用平均分覆盖事实失败。候选由开发失败提出，未运行的留出不用于修订。

查阅 [promptfoo LLM Rubric 官方文档](https://github.com/promptfoo/promptfoo/blob/0c7829916095bf274501b2b6438a0223d66b966e/site/docs/configuration/expected-outputs/model-graded/llm-rubric.md)：评价参数应固定，明确区分分数与通过状态；缺少 pass 的配置可能产生默认通过。本项目要求每一项明确返回布尔判断，程序校验完整性；无效评价停止，不能计入反例校准成功。没有把模型评分当作真人学习证据。

两份官方资料副本、提交和 SHA-256 在 `runs/internal-training/github-methods/references.json`。仅借鉴上述设计，并未运行这两个仓库的基准或宣称获得其效果。

## 复现

Windows PowerShell，在项目根目录使用系统新版 Node：

```powershell
$env:Path = 'C:\Program Files\nodejs;' + $env:Path
$env:TUTOR_TRAINING_DIR = 'runs/internal-training/cycle-2'
$env:TUTOR_TRAINING_PREVIOUS_DIR = 'runs/internal-training/cycle-1'
npm.cmd run training:prepare  # 零模型调用，冻结材料、规则、评价与引擎
npm.cmd run training:m1
npm.cmd run training:m2       # 开发候选失败则不调用模型
npm.cmd run training:m3       # M2 未完成则拒绝启动
```

运行后查看该周期 `summary.json`、`records/training/report.json`、`records/training/protocol.json`；每次实际输入保存于 `records/provider-inputs/`。运行证据为本机忽略文件，代码与本记录提交 Git。修改候选、输入、评价、引擎或模型配置后不能继续原协议；新周期必须显式保留前序预算。
