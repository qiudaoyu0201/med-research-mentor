# 科研学习助手

帮助医学科研初学者快速使用三个核心能力：**论文讲解、论文 PPT 生成、研究方案生成**。桌面网页沿用 iOS／iPadOS 风格；笔记、附件、来源、偏好和版本服务正常流程。

当前工作以[落地方案 v2.8](docs/科研能力培养与三类Agent协作_整体落地方案.md)为准。[内部训练第一轮方案](docs/内部训练第一轮_落地方案.md)明确实施与验收；[周期 1 记录](docs/内部训练第一轮_周期1记录.md)与[周期 2 记录](docs/内部训练第一轮_周期2记录.md)保存累计 44 次尝试、质量失败及成本，教学候选均未启用。[最新完成度复核](docs/整体完成度复核_2026-10-07.md)记录多角度判断及补修；[产品收尾验收](docs/产品收尾_配图裁剪与日常错误验收.md)记录配图和真实生成检查；[整体复查](docs/科研能力培养与三类Agent协作_整体复查与优化记录.md)保留基线问题及关闭依据。

## 启动和入口

需要 Node.js 22.13 或更新版本。在 Windows 双击 **启动导师.cmd**，保持启动窗口运行，访问 <http://127.0.0.1:4317/>。结束服务按 Ctrl+C。脚本优先使用新版系统 Node，避免其他软件自带的旧 Node 抢占 PATH。

开发启动：

```powershell
$env:Path = 'C:\Program Files\nodejs;' + $env:Path
npm.cmd ci
npm.cmd run dev
```

修改源码后运行 `npm.cmd run build` 并重启服务。正式构建使用 `npm.cmd start`。用户已有预览入口：<http://127.0.0.1:4328/>。

首页导航直接提供论文研究、PPT 汇报和研究方案。历史 `/assistant`、`/prototype` 留作兼容／固定视觉对照，产品导航不展示它们，不将原型当真实生成入口。

## 怎样使用

1. **论文讲解：** 导入 PDF 后提问。输入区加号可添加 PDF／PNG／JPEG，支持拖入、粘贴和发送前移除。PDF 上限 30 MiB／100 页；图片单项 8 MiB，一次最多四项。无可用文字的 PDF 不自动 OCR，可补文字原文。
2. **查看原文：** 回答保留一个 PDF 入口，同页引用合并。选中文字继续提问；“框选局部”可查看图片、段落或较大范围，返回整页继续阅读。选区坐标在浏览器按论文／版本／页／来源保存，不修改原 PDF。
3. **PPT 汇报：** 选择论文，要求可留空，按需选择页数、带上笔记、勾选完整演讲稿。逐页阅读或修改；“编辑这一页 → 配图与裁剪”可换原图或 PDF 页、框选局部并保存核对。完整稿可补写、编辑和独立导出。
4. **研究方案：** 输入医学研究问题即可生成，条件和来源可以逐步补。阅读设计理由，按需编辑或提出改稿要求，保存后核对。未知条件保留为未知，不填造样本量、结果或操作参数。
5. **取消与导出：** 在当前进度处取消任务，排队／执行都支持；旧产物和草稿保留。PPT、研究方案只导出成功完成当前核对的保存版本，失败／未核对／有阻断问题时不可导出。手改方案和恢复的方案需重新核对；先前成功历史稿仍可选定导出。
6. **笔记和偏好：** “资料 → 我的笔记 → 新建笔记”可直接打字，也能保存回答。设置分别控制讲解程度和学习重点，按聊天保存；自然语言本轮调整不自动变成永久偏好。PPT／方案的资料浮层关闭后返回原位置。

用户不必完成课程或考试，不需要先建研究方案才能生成论文 PPT。必要的材料、条件、进度、来源、修改和保存保留；辅助内容按需展开，整体布局不因内部训练增加步骤。

## 模型和数据

默认实时推理使用本机已有的 Codex ChatGPT 登录。程序支持显式配置 HTTPS Chat Completions 兼容提供方：

| 环境变量                                                       | 用途                                             |
| -------------------------------------------------------------- | ------------------------------------------------ |
| `TUTOR_PROVIDER=compatible`                                    | 显式选择兼容接口                                 |
| `TUTOR_MODEL_BASE_URL`                                         | HTTPS 基础地址，含实际 `/v1` 等前缀              |
| `TUTOR_MODEL`、`TUTOR_MODEL_API_KEY`                           | 型号和服务端凭据                                 |
| `TUTOR_MODEL_IMAGES=true`                                      | 显式声明所选型号可用图像输入                     |
| `TUTOR_MODEL_OUTPUT_MODE`                                      | 默认 `json_object`；确认支持后可选 `json_schema` |
| `TUTOR_MODEL_MAX_INPUT_CHARS`、`TUTOR_MODEL_MAX_OUTPUT_TOKENS` | 输入／输出额度                                   |

程序读取进程环境，不自动加载 `.env`；重启生效。凭据不进入前端、Git 和普通日志。配置存在不等于目标模型已验收，失败不会静默换模型。`npm.cmd run model:check` 读取配置／登录及目录；加 `-- --generate` 才发起实际短文本请求。文本、图像、结构与取消能力须按目标型号单独实测。

本地界面不等于离线推理：实时材料会发送给所选模型服务。文件和记录保存在 `data/` 或 `TUTOR_DATA_DIR`，导出在 `exports/`，检查产物在 `runs/`，这些目录不提交 Git。服务只监听 127.0.0.1，并检查 Host／Origin。运行时模型没有任意 shell、网页、MCP 或应用工具权限。

示例使用本机 Xu 2018 PDF；缺该文件时回到标明范围的局部中文摘要。新任务优先采用定位好的图件，旧版本原页绑定保留。普通 PDF 也提供图注／绘图几何可定位的图件，无法定位时保留原 PDF 和手动裁剪。历史 Figure 1m 分母依据不足、早期汇报内容验收失败和真人效果未验继续保留。

### 保存与以后部署

已保存的论文、笔记、聊天、PPT／方案版本保存在服务端 `data/` 或 `TUTOR_DATA_DIR`；导出文件在 `exports/`。浏览器未保存草稿、偏好和选区属于当前浏览器，待发附件还使用 IndexedDB。需要保留已保存资料时备份数据目录与原 PDF／附件，导出文件另行备份；浏览器缓存不代替服务端备份。

当前为本机单用户服务，没有账号和用户数据隔离。若以后多人共用部署，需要账号、按用户隔离的记录／文件访问、持久化服务器存储与备份；已保存资料可登录后恢复，导出下载到各自设备。清浏览器缓存会丢未保存草稿。此处记录部署边界，本轮不新增账号后台。
