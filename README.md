# 医学科研入门导师 · 初版 0.1

本机网页已提供论文带读、方法讲解、图表解读、基础汇报 PPT 四个入口。默认以固定示例打开；实时模式使用本机已登录的 Codex 和 GPT-6.1 Sol。

已接入主助手、连续会话、共享预算、完整 PPT 试读、精确缓存与内容回放。本轮新增独立基础目录、通用 Figure 证据登记、一次补讲、来源快照与版本校验；独立方法不加载默认论文，换论文重新绑定证据。原有四入口使用同一后端，主对话前端留到下一阶段。实现与真实验证见[基础资料迁移验收](docs/基础资料迁移与四场景验证_验收.md)，历史基线见[后端优化验收](docs/主助手后端优化验收.md)。

## 启动

Windows 双击 **启动导师.cmd**，保持启动窗口运行，浏览器访问 <http://127.0.0.1:4317>。退出按 Ctrl+C。脚本优先选择系统安装的新版 Node，避免其他软件自带的旧 Node 抢占 PATH。

需要 Node.js 22.13 或更新版本。当前已验证环境：Node 24.19.0、Codex CLI 0.160.0、Windows、Microsoft Edge。首次使用脚本执行 `npm ci`，已有依赖时不会重新安装。更新源码后执行 `npm run build`。

开发启动：

```powershell
$env:Path = 'C:\Program Files\nodejs;' + $env:Path
npm.cmd ci
npm.cmd run dev
```

## 试用顺序

1. 打开示例论文，选带读、方法或图表，再打开教学示例。点击依据回到左侧证据位置，术语可展开和收藏。
2. 在设置中切换实时模式，或点击“切换实时模式”。自由问题进入主助手→教学→模拟新手→来源核对，必要时修订一次并复查。明确任务最多六次，含一次模型规划最多七次。会话自动保存已教概念与学习摘要；精确缓存命中零次生成，失败不自动重试。
3. 上传文本型 PDF（30 MB、100 页以内），检查提取文字、选择当前页资料。拖动圈选图件，补充完整图注；可保存圈选与图注，供后续原图嵌入。扫描文件可查看页面、手动补文本，不提供自动 OCR。
4. 打开汇报 PPT，调整标题、要点、讲稿和顺序，再生成 PPTX。可直接生成示例大纲；上传论文需先实时生成并核对大纲。
5. 设置面板可恢复或删除历史记录。“读过”“仍不理解”“主动标记已理解”分别保存，不由点击或停留推断掌握。
6. 规则比较面板保存基线与候选。静态模式零模型调用，只检查规则完整性；实时模式每批至多四个案例，基线与候选各最多 32 次，包含内容审阅。精确基线可复用，候选实跑。内容或评价未完成时不能保留候选；保留记录存入本机资料。

## 模型与数据

`npm run model:check` 只检查登录和目录；加 `-- --generate` 发起一次短文本请求，使用现有账号额度。目录存在不代表有推理权限。`CODEX_BIN` 可指定 Codex 可执行文件；不要求粘贴密码或 token，不读取或修改登录文件，不使用环境中的付费 API Key。

实时资料会发送至云端，文件和运行记录保存在 `data/`，导出在 `exports/`，检查截图在 `runs/`。这些目录不提交 Git。服务仅监听 127.0.0.1，并检查 Host 与 Origin，不用于公网部署。默认关闭环境、shell、网页、MCP 和应用工具访问；发现非文本工具项即停止任务。

模拟新手只取得固定画像、问题、可见讲解/图注、已教概念和复读断点；不取得原始方法资料、完整核对报告或案例参考答案。核对角色取得本任务材料，独立检查。相同模型仍可能共同出错。

这里的“模拟新手”目前是试读检查角色，尚未实现并验证持续学习的新手模拟环境，也未接入 TinyTroupe、CAMEL 或 Generative Agents。已教概念表示讲解出现过，不表示学生已掌握。项目源码对照、skill 模块化和修正后的模拟方案见[源码核查与方案纠正](docs/Skill模块化与新手模拟_源码核查.md)。

## 验证与资料范围

```powershell
npm.cmd run check          # 类型、构建与流程检查
npm.cmd run test:browser   # 先启动服务；使用已安装的 Edge
npm.cmd run eval           # 静态规则回放，零模型调用
npm.cmd run eval -- --live --small # PCR 开发 + Ct 留出，最多 28 次（含基线、候选及内容审阅）
npm.cmd run assistant:check       # Figure 1 固定资料、图注和方法位置，零模型调用
npm.cmd run assistant:check -- --live # 一次组合任务，最多 6 次；保存调用与产物记录
npm.cmd run transfer:check            # 两篇论文原图、图注、方法与基础限额，零模型调用
npm.cmd run transfer:check -- --live --batch A # 连续追问＋换论文，含独立评价
npm.cmd run transfer:check -- --live --batch B # 独立方法＋三页汇报，含独立评价
```

当前本机已接入 Xu 2018 正文 PDF，示例可查看 15 页原文；Figure 1、6 提供图件所在原页并保留图注，PPT 按比例嵌入原页。固定讲解仍是局部教学示例，自动提取的文字尚未逐段校对。没有正文文件的安装会回退到注明范围的局部中文证据摘要，缺图时明确占位。讲解使用已登记正文证据；本轮按用户授权额外核验了补充材料，具体已读范围见迁移验收。临床适配、所有图形类型、真实学习效果尚未验证。

详见 [初版验收与已知问题](docs/初版验收与已知问题.md) 与 [参考来源与复用记录](docs/参考来源与复用记录.md)。

新后端支持创建／恢复会话、提交消息、查询轮次及取消，接口示例见后端验收文档。更改源码后重启服务以加载新实现。连接复用、检查并行与两个任务组仍按 P2 单独评价，当前保持独立角色会话和串行检查。

基础目录目前有 17 条已登记资料，随启动接口提供给现有来源面板。四场景材料验证还需要本地 Hewitt 2012 正文；可用环境变量 `TUTOR_HEWITT_PDF` 指定 PDF 路径。论文、运行数据和导出文件按既有规则不提交，缺材料会记录未就绪，不能计为通过。
