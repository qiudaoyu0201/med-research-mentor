# 参赛支撑材料清单

日期：2026-10-09。此清单用于整理提交材料，不表示主办方已经收件或接受延期模型适配。

## 建议提交的脱敏材料

1. 作品本地运行录屏：空首页、论文带读、选句追问、PDF 对照、PPT 预览下载、研究方案生成。
2. 真实产物：带读回答摘录、独立讲述提示、可编辑 PPTX、研究方案 Markdown/Word。逐项删除 API key、个人路径和完整账本中的敏感字段。
3. 三智能体闭环记录：冻结问题与材料范围、助手输出、模拟小白断点、校验意见、修订前后和同条件比较。说明这是内部工程诊断，不是真人效果。
4. 调用与失败边界：保留请求终态、取消、未知用量、重启恢复和重复请求防护；报告中只展示必要的模型、范围、耗时和已知 token，不展示凭据。
5. PDF 与图件证据：Xu 论文实际使用的页范围、PDF/图件联动截图；复杂定位失败时也保留失败说明。
6. 方案审核证据：首稿阻断、修订稿、仍保留的非阻断警告，说明不是无条件执行方案。
7. 模型说明：当前为 klapi 中转的 gpt-5.6-sol，国内模型迁移是计划，不声称已适配；如后续适配，另附型号、版本和独立验证结果。
8. 开源与参考记录：列出参考过的 GitHub Skill、许可核对状态、自有改造内容，不把未安装或未试跑项目写成集成。

## 目前不能作为支撑材料的内容

- 模拟小白的“理解”直接当作本科生学习效果。
- 单篇论文前两页的成功任务当作全医学或全文 PDF 能力。
- PPTX 文件存在当作逐页可读、可编辑和内容准确已经验收。
- 中转地址当作国内模型适配证明。
- 计划中的录屏、报名表或二审适配当作已完成交付。

## 提交前核对

- [ ] 按公告核对 Word 不超过 5000 字、三号黑体标题、小四宋体、1.5 倍行距。
- [ ] 视频控制在 3—6 分钟，并展示真实操作和真实效果。
- [ ] 报名表字段从官方页面核对后填写；当前尚未取得字段确认。
- [ ] 所有截图、PDF、日志和产物脱敏，来源与日期可追溯。
- [ ] 说明中分开当前中转证据、国内模型计划和真人未验收状态。
