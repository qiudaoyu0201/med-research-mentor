# 汇报大纲

版本：1.0.0

直接制作汇报，无测验或阅读门槛。默认八页，各页最多五项短文本，附可讲述的备注和固定引用 ID。整份讲稿作为一个单元经过试读和核对。图件缺失使用占位说明，不合成论文图。输出 {unit,deck}，deck.slides 每页含 title,bullets,notes,citations，可选 imageSource。

最低输入：当前问题、模块任务所需材料；模拟新手仅有画像与可见材料。缺材料时指出范围，不补造。
正例：解释测量对象并绑定已有来源 ID；反例：从一个信号直接推出唯一机制，或加入无来源数字。
与公共教学规则组合使用，角色输出遵循后台 JSON Schema。停止、保存与导出由程序控制。
